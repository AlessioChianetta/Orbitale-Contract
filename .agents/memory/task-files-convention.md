---
name: Task file convention
description: Where and how the owner wants work plans written.
---

The owner wants work plans as Markdown files in `task-da-fare/` named `NNN-slug.md` (001, 002, …), written in Italian.

Completed tasks are moved to `task-da-fare/fatti/` (owner request, 16/10/2026).

**Why:** the user asked for this explicitly.

**How to apply:** when asked to "creare una task", add the next numbered file there (do not use the project-tasks queue unless in Plan mode).
